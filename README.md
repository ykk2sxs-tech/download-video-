# โหลดวิดีโอ — ดาวน์โหลดวิดีโอจาก YouTube / Facebook / Zoom ด้วยการวางลิงก์

แอปบนเครื่องตัวเอง (เปิดผ่านเว็บเบราว์เซอร์) แค่ **คัดลอกลิงก์ → วาง → กดดาวน์โหลด**

| แพลตฟอร์ม | ลิงก์ที่รองรับ (ตัวอย่าง) |
|---|---|
| YouTube | `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…` |
| Facebook | `facebook.com/watch?v=…`, `fb.watch/…`, `facebook.com/reel/…`, วิดีโอในโพสต์ |
| Zoom | บันทึกการประชุมบนคลาวด์ `zoom.us/rec/share/…`, `zoom.us/rec/play/…`, `zoom.us/clips/share/…` |

## ความสามารถ

- วางข้อความที่มีลิงก์ปนอยู่ได้เลย (เช่น "ดูคลิปนี้ https://fb.watch/xxx") แอปจะดึงลิงก์ออกมาเอง
- แสดงตัวอย่าง: รูปปก, ชื่อคลิป, ความยาว, ความละเอียดสูงสุดที่มี
- เลือกคุณภาพ: **1080p / 720p / 480p / สูงสุด (4K)** หรือ **MP3 เสียงอย่างเดียว**
  - 1080p/720p/480p เลือกไฟล์แบบ H.264 + AAC ก่อน เปิดได้ทุกเครื่อง (Windows, มือถือ, PowerPoint)
- แถบความคืบหน้า, ความเร็ว, เวลาที่เหลือ, ปุ่มยกเลิก, โหลดพร้อมกันได้ 2 รายการ
- **Zoom ที่ตั้งรหัสผ่าน** → ใส่ Passcode ใน "ตัวเลือกเพิ่มเติม"
- **วิดีโอส่วนตัว / กลุ่มปิด Facebook** → เลือกเบราว์เซอร์ที่ล็อกอินไว้ ให้แอปใช้ cookies จากเบราว์เซอร์นั้น
- ข้อความ error เป็นภาษาไทย พร้อมคำแนะนำวิธีแก้

ไฟล์ทั้งหมดถูกบันทึกในโฟลเดอร์ `downloads/` ข้างโปรแกรม (กดปุ่ม "เปิดโฟลเดอร์ที่เก็บไฟล์" ในแอปได้)

## วิธีติดตั้งและเปิดใช้งาน

### Windows — ไฟล์ติดตั้ง .exe (ง่ายที่สุด ไม่ต้องติดตั้ง Python)

1. ดาวน์โหลด **`VideoDownloader-Setup.exe`** เวอร์ชันล่าสุด:
   <https://github.com/ykk2sxs-tech/download-video-/releases/latest/download/VideoDownloader-Setup.exe>
   (หรือเปิดหน้า [Releases](https://github.com/ykk2sxs-tech/download-video-/releases/latest) แล้วเลือกไฟล์ในหัวข้อ Assets)
2. ดับเบิลคลิก `VideoDownloader-Setup.exe` → กด **Next / Install** (ไม่ต้องใช้สิทธิ์ Admin)
   - ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน **"Windows protected your PC"** ให้กด **More info → Run anyway**
     (ขึ้นเพราะโปรแกรมยังไม่ได้ซื้อใบรับรอง code signing ไม่ใช่ไวรัส)
3. เปิดโปรแกรมจากไอคอน **"โหลดวิดีโอ"** บนหน้าจอ → เบราว์เซอร์จะเปิดหน้าแอปขึ้นมาเอง
4. ไฟล์ที่ดาวน์โหลดจะอยู่ที่ **`Downloads\VideoDownloader`**
5. ปิดหน้าต่างสีดำเพื่อหยุดโปรแกรม

มีแบบ **Portable** (ไม่ต้องติดตั้ง) ด้วย: แตกไฟล์ `VideoDownloader-Portable.zip` แล้วดับเบิลคลิก `VideoDownloader.exe`

> โปรแกรม .exe ไม่อัปเดต yt-dlp เอง — ถ้าวันหนึ่งโหลดจาก YouTube/Facebook ไม่ได้
> ให้ดาวน์โหลด Setup.exe ตัวใหม่มาติดตั้งทับ (ข้อมูลและไฟล์เดิมไม่หาย)

### Windows — รันด้วย Python (อัปเดต yt-dlp อัตโนมัติทุกครั้งที่เปิด)

1. ติดตั้ง **Python 3.10 ขึ้นไป** จาก <https://www.python.org/downloads/>
   (หน้าแรกของตัวติดตั้ง **ติ๊ก "Add python.exe to PATH"**)
2. ดาวน์โหลดโปรเจกต์นี้ (ปุ่ม **Code → Download ZIP** บน GitHub) แล้วแตกไฟล์
3. ดับเบิลคลิก **`start.bat`**
   - ครั้งแรกจะติดตั้งโปรแกรมที่จำเป็นให้อัตโนมัติ (ประมาณ 1–3 นาที)
   - เบราว์เซอร์จะเปิดหน้า <http://127.0.0.1:8765> ขึ้นมาเอง
4. ใช้งานเสร็จ ปิดหน้าต่างสีดำ (Command Prompt) เพื่อหยุดแอป

### macOS / Linux

```bash
./start.sh
```

### ติดตั้งเอง (สำหรับผู้ที่คุ้นกับ Python)

```bash
python -m venv venv
venv/bin/pip install -r requirements.txt      # Windows: venv\Scripts\pip ...
venv/bin/python app.py                        # Windows: venv\Scripts\python app.py
```

ตัวเลือกเพิ่มเติม (ตั้งเป็น environment variable):

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `8765` | พอร์ตของแอป |
| `DOWNLOAD_DIR` | `./downloads` | โฟลเดอร์เก็บไฟล์ |
| `HOST` | `127.0.0.1` | ตั้งเป็น `0.0.0.0` ถ้าต้องการให้เครื่องอื่นในวง LAN ใช้ได้ |
| `NO_BROWSER` | – | ตั้งค่าใดก็ได้เพื่อไม่ให้เปิดเบราว์เซอร์อัตโนมัติ |

## ส่วนเสริมเบราว์เซอร์ (Chrome / Edge / Brave)

ดาวน์โหลดได้ในคลิกเดียวจากหน้าวิดีโอ ไม่ต้องคัดลอกลิงก์ — ส่วนเสริมจะส่งลิงก์ไปให้แอป "โหลดวิดีโอ" บนเครื่องเป็นผู้ดาวน์โหลด
(จึงต้องติดตั้งแอปด้วย; ถ้าแอปปิดอยู่ ส่วนเสริมมีปุ่ม **เปิดแอป** ให้)

**ติดตั้ง** (ทำครั้งเดียว)

1. เปิดแอป → เลื่อนลงล่างสุด กด **"ติดตั้งส่วนเสริมเบราว์เซอร์"** → **เปิดโฟลเดอร์ส่วนเสริม**
   (ถ้าใช้แบบ Python: โฟลเดอร์ `browser-extension/` ในโปรเจกต์นี้ / หรือแตกไฟล์ `VideoDownloader-Extension.zip` จากหน้า Releases)
2. ในเบราว์เซอร์ไปที่ `chrome://extensions` (Edge: `edge://extensions`)
3. เปิด **Developer mode** (โหมดนักพัฒนาซอฟต์แวร์)
4. กด **Load unpacked** (โหลดส่วนขยายที่คลายการแพ็ก) แล้วเลือกโฟลเดอร์จากข้อ 1
5. กดไอคอนจิ๊กซอว์บนแถบเครื่องมือ แล้วปักหมุด "โหลดวิดีโอ"

**ใช้งาน**

- อยู่หน้าวิดีโอ → กดไอคอน "โหลดวิดีโอ" → เลือกคุณภาพ → **ดาวน์โหลด**
- หรือ **คลิกขวา** ที่ลิงก์วิดีโอ (เช่น "เวลาโพสต์" ของวิดีโอใน Facebook) → **ดาวน์โหลดวิดีโอจากลิงก์นี้**
- ระบบจะ **แจ้งเตือน** เมื่อดาวน์โหลดเสร็จ กดปุ่มในแจ้งเตือนเพื่อเปิดไฟล์ได้เลย
- **วิดีโอส่วนตัว / กลุ่มปิด / YouTube ขอยืนยันตัวตน** → ติ๊ก **"ใช้การล็อกอินของเบราว์เซอร์นี้"**
  ส่วนเสริมจะส่ง cookies ของเว็บนั้น (เฉพาะ YouTube/Facebook/Zoom) ไปให้แอปบนเครื่องเท่านั้น
  ใช้ในหน่วยความจำระหว่างดาวน์โหลด ไม่บันทึกลงไฟล์ และไม่ส่งไปที่อื่น

> ทำไมไม่อยู่ใน Chrome Web Store: นโยบายของ Google ไม่อนุญาตส่วนเสริมที่ดาวน์โหลดวิดีโอ YouTube
> จึงต้องติดตั้งแบบ Load unpacked (Chrome อาจเตือนเรื่อง Developer mode ตอนเปิดเบราว์เซอร์ กดปิดได้)
> Firefox ยังไม่รองรับ

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| YouTube ขึ้น "Sign in to confirm you're not a bot" | เปิด "ตัวเลือกเพิ่มเติม" → เลือกเบราว์เซอร์ที่ล็อกอิน YouTube ไว้ (แนะนำ Firefox) |
| Facebook บอกว่าวิดีโอส่วนตัว / ต้องล็อกอิน | เลือกเบราว์เซอร์ที่ล็อกอิน Facebook ไว้ |
| เลือก Chrome / Edge แล้วอ่าน cookies ไม่ได้ | ใช้**ส่วนเสริมเบราว์เซอร์**แล้วติ๊ก "ใช้การล็อกอินของเบราว์เซอร์นี้" แทน (Chrome รุ่นใหม่บน Windows เข้ารหัส cookies แบบที่โปรแกรมภายนอกอ่านไม่ได้) หรือใช้ Firefox |
| Zoom ขอ Passcode | ใส่รหัสในช่อง "รหัสผ่าน Zoom" (รหัสอยู่ในข้อความที่ได้รับพร้อมลิงก์) |
| เคยโหลดได้ แต่วันนี้โหลดไม่ได้ | ปิดแล้วเปิด `start.bat` ใหม่ — แอปจะอัปเดต yt-dlp ให้อัตโนมัติ (เว็บต่าง ๆ เปลี่ยนระบบบ่อย) |
| ลิงก์ Zoom แบบ `…/j/123456` | นั่นคือลิงก์ **เข้าประชุม** ไม่ใช่ลิงก์ **บันทึกการประชุม** — ต้องใช้ลิงก์ที่มี `/rec/` |

## ข้อควรทราบ

- ใช้ดาวน์โหลดเฉพาะวิดีโอที่คุณมีสิทธิ์ เช่น บันทึกการประชุมของบริษัท คลิปของตัวเอง หรือคลิปที่เจ้าของอนุญาต
  การดาวน์โหลดเนื้อหาที่มีลิขสิทธิ์โดยไม่ได้รับอนุญาตอาจผิด พ.ร.บ.ลิขสิทธิ์ และข้อตกลงการใช้งานของแต่ละแพลตฟอร์ม
- แอปทำงานบนเครื่องของคุณเท่านั้น (ค่าเริ่มต้นเปิดรับเฉพาะ `127.0.0.1`) ไม่ส่งลิงก์หรือไฟล์ไปที่เซิร์ฟเวอร์อื่น
- ไลฟ์สดที่ยังไม่จบ แนะนำให้รอจนจบแล้วค่อยดาวน์โหลด

## โครงสร้างโปรเจกต์

```
app.py              เซิร์ฟเวอร์ Flask + ระบบคิวดาวน์โหลด (ใช้ yt-dlp)
packaging/          สคริปต์สร้าง .exe (PyInstaller), ตัวติดตั้ง (Inno Setup), smoke test
.github/workflows/  build + ทดสอบไฟล์ .exe บน Windows อัตโนมัติ
static/index.html   หน้าจอผู้ใช้ (ภาษาไทย, รองรับมือถือ/โหมดมืด)
browser-extension/  ส่วนเสริม Chrome/Edge (Manifest V3) ที่ส่งลิงก์ไปให้แอป
start.bat           เปิดแอปบน Windows (ติดตั้ง + อัปเดตให้อัตโนมัติ)
start.sh            เปิดแอปบน macOS / Linux
tests/              ชุดทดสอบ (pytest)
```

### เบื้องหลัง

- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — ตัวดาวน์โหลด รองรับ YouTube, Facebook, Zoom
- **deno** — JavaScript runtime ที่ yt-dlp ต้องใช้ถอดรหัสลิงก์วิดีโอของ YouTube (ติดตั้งผ่าน pip ให้อัตโนมัติ)
- **ffmpeg** — รวมไฟล์ภาพ+เสียง และแปลง MP3 (ใช้ตัวในเครื่องถ้ามี ไม่มีจะใช้ตัวจาก `imageio-ffmpeg`)

รันชุดทดสอบ:

```bash
venv/bin/pip install pytest
venv/bin/python -m pytest -q
```

### สร้างไฟล์ .exe

ทำอัตโนมัติด้วย GitHub Actions (`.github/workflows/build-windows.yml`) ทุกครั้งที่ push / เปิด PR:
build ด้วย PyInstaller → ทดสอบโปรแกรมที่ build แล้ว → สร้างตัวติดตั้งด้วย Inno Setup → ติดตั้งจริงแบบเงียบแล้วทดสอบซ้ำ

- ทุกครั้งที่มีการ merge เข้า `main` จะสร้าง **Release ใหม่** (เวอร์ชัน `v1.0.<เลข run>`) พร้อมไฟล์ Setup.exe และ Portable.zip
- ต้องการ build ใหม่ด้วย yt-dlp ล่าสุดโดยไม่แก้โค้ด: หน้า Actions → **Build Windows app → Run workflow** (ได้ Release ใหม่เช่นกัน)
- push tag `v*` (เช่น `v2.0.0`) ก็สร้าง Release ด้วยชื่อ tag นั้น

build เองบนเครื่อง (ได้โปรแกรมของระบบปฏิบัติการที่ใช้ build):

```bash
pip install -r requirements.txt -r packaging/requirements-build.txt
python packaging/build.py                                         # ได้ dist/VideoDownloader/
python packaging/smoke_test.py dist/VideoDownloader/VideoDownloader.exe
```
